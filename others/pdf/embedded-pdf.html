PDF embedded in a page

An ordinary page that shows a PDF inside an <iframe> — the shape Google Drive and Gmail use to preview attachments, and course sites to show a handout.

What to check. The PDF below is not a PDF tab — it is a frame inside this page, so the viewer sits at a page offset and this page competes with it for the same Read command. Host-page sentences here begin with “This page…”; every sentence in the document begins with something else, so you can always hear which one is being read.

  1. Press play with nothing selected. The document reads from the top — “Readalix reads PDFs aloud…” — with each spoken word highlighted inside the frame. No “select text first” note, and no blue select-all tint left behind on the pages.
  2. Select a passage inside the PDF, then play. Only that passage is read, and the blue selection disappears as reading starts so it can’t bury the word highlight.
  3. Select a paragraph of this page, then play. The page text is read and the document stays silent — the page owns that read.
  4. Click anywhere on the PDF while it reads. Reading stops. Scrolling it does not.
  5. Escape stops, and the read shortcut toggles, while the focus is inside the PDF.

This page is the host document, and this paragraph belongs to it rather than to the PDF below. This page exists to sit around the embedded viewer so there is real page text above and below it to select. This page should be read aloud in this voice only when one of its own paragraphs is selected first.

This page continues after the embedded document, so the frame is not the last thing on it. This page keeps a second selectable block of host text down here, useful for checking that a selection made after the PDF still wins over it.
